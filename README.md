# Hi, I'm Masoud 👋

Electrical engineer by degree, **vibe coder by practice**. ⚡💻

I started building software with AI back in the **GPT-3.5 era**. What began as *"let's see if GPT can help me write this script"* turned into a much bigger rabbit hole. 🐇

I've watched AI go from autocomplete, to coding assistants, to increasingly capable **agents that can reason, use tools, inspect codebases, and actually build things**. 🤖

And somewhere along the way, I started wondering:

> **What happens when the machines get really good at building, and humans become the bottleneck?** 🧠

So that's what I'm exploring. 🔭
